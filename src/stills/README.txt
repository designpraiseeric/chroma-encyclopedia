CHROMA ENCYCLOPEDIA — REFERENCE STILLS

Put one frame grab per film in this folder, named exactly as in _manifest.csv
(e.g. moonlight.jpg, in-the-mood-for-love.jpg). .jpg, .webp or .png all work.
One grab per film fills every section that cites it. Suggested size: 1280 px wide, 16:9 or the film's own ratio.

Pick the frame that shows the color idea the entry describes (the note beside
each film in the encyclopedia tells you what that is).

Use frames from sources you have the right to use (your own discs/files, licensed
stills). Images in this folder stay local unless you choose to upload them.

../renders/  holds catalog render plates for section heads (psy-red.jpg, pal-mono.jpg …).
