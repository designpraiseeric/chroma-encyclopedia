# Git identity

Commit as the repo owner so GitHub credits the work to them. Before your first commit in any session, run:

```
git config user.name "DesignPraise"
git config user.email "110134819+designpraiseeric@users.noreply.github.com"
```

Never author or commit as `Claude <noreply@anthropic.com>`. A `Co-Authored-By: Claude` trailer in the message is fine.
